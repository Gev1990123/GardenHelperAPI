# GardenHelper API

GardenHlper is an open API for gardening data - starting with plants and growing tips.

## Features
- REST AP built with FastAPI
- Focus on plant data first
- Roadmap for more gardening resources

## Getting Started
```bash
git clone
https://github.com/Gev1990123/GardenHelperAPI.git
cd GardenHelperAPI
python3 -m venv venv
source venv/bin/activate # (on Windows: venv\Scripts\activate)
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Visit http://127.0.0.1:8000/docs for the interactive API docs
